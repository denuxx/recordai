# Record AI

Голосовой ввод для Mac. Нажали горячую клавишу, сказали — текст появился там, где стоит курсор. С пунктуацией, сленгом и английским посреди русской речи. Работает без интернета, бесплатно.

**Сайт:** https://denuxx.github.io/recordai/

**Скачать:** [Record-AI.dmg](https://github.com/denuxx/recordai/releases/latest/download/Record-AI.dmg) (macOS 14+, Apple Silicon)

## Установка

1. Откройте `Record-AI.dmg` и перетащите Record AI в папку «Программы».
2. При первом запуске macOS предупредит, что не может проверить разработчика: нажмите «Готово», затем откройте **Системные настройки → Конфиденциальность и безопасность** и нажмите **Всё равно открыть**.
3. Разрешите доступ к микрофону и включите Record AI в **Универсальном доступе**, чтобы приложение могло вставлять текст.
4. Подождите, пока скачается и подготовится модель (~1,6 ГБ, первый раз до 15 минут).

В этом репозитории только сайт и готовые сборки приложения.
